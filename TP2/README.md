# AMBER CLUB — TP2 / SP2 — Aplicaciones Web I

## Abrir el proyecto
Abrí `index.html` en cualquier navegador actualizado. No requiere instalaciones ni conexión a internet.

## Páginas
- `index.html`: inicio (en la raíz)
- `catalogo.html`: catálogo, filtros semánticos no funcionales
- `producto.html`: detalle demostrativo de Khamrah (enlace común de las tarjetas)
- `nosotros.html`: información institucional
- `contacto.html`: formulario sin envío real
- `carrito.html`: alternativa HTML del futuro panel de carrito

## Recursos
- `assets/img`: ilustraciones SVG originales del proyecto, no fotografías comerciales
- `assets/audio` y `assets/video`: reservados, no se requieren archivos multimedia
- `docs`: informe PDF de entrega

## Alcance
Solo HTML5 y archivos SVG. No CSS, JavaScript, backend, checkout real ni filtros activos. Formularios de demostración sin almacenamiento ni envío efectivo. Los productos y precios son muestras para estructura; verificar antes de publicar.

## Observación
El TP1 consideraba el carrito un panel dinámico y `producto.html?id=...` para cada ficha. En esta fase se implementa una página de carrito accesible y una ficha de ejemplo en `producto.html`, dejando esas funciones dinámicas para futuras entregas.
