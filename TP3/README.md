# AMBER CLUB — TP3 / SP3

Trabajo de Aplicaciones Web I, Prof. Andrés Senn.

## Ejecutar
Abrir `index.html` desde la raíz del proyecto en un navegador. No requiere instalación ni conexión.

## Archivos
- `*.html`: seis páginas semánticas del TP2 con clases CSS.
- `assets/css/styles.css`: hoja de estilos única, variables CSS, BEM y media queries.
- `assets/img/`: recursos SVG locales ilustrativos.
- `assets/audio/` y `assets/video/`: carpetas previstas para expansión.
- `docs/Informe_TP3_Amber_Club.pdf`: informe.

## Responsive
Escritorio >900 px: 3 columnas; tablet 601–900 px: 2 columnas; móvil hasta 600 px: 1 columna.

## Alcance
Sin JavaScript ni backend: filtros, agregar al carrito y formulario no procesan información. No se publican precios reales.
